# 项目内 RAG 运行资料

本目录从原 RAG 仓库复制运行所需内容，网站默认只读取这一份，不依赖原仓库目录。

- `student_handbook_rag/`：公共 `HandbookRAG` Python 接口。
- `scripts/`：该接口和单次问答 CLI 实际依赖的检索、重排、生成与复核模块。
- `config/`：公开配置和提示词；`output/`：已有文本分块、向量、批次及校验资料。
- `README.md`：上游公开教程，供首页和安装助手读取；来源许可保留在 `LICENSE`。
- `upstream.json`：原仓库地址、提交和逐文件 SHA-256；不包含本机凭据。
- `.runtime/`：忽略的本机凭据与查询缓存，不进入 Git。

本目录保留上游运行文件的原始字节，不批量格式化、不重新生成向量。
网站适配逻辑放在 `../app/services/rag.py`。有实际需求修改运行快照时，
同时明确来源清单中的变化并验证索引完整性；不要把快照当作另一个独立开发仓库。
这里只有运行依赖，没有 PDF 解析、全量向量构建等离线工具和开发环境。
