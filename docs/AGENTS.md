# 文档职责

- `README.md` 只负责导航；新增、移动、删除文档时同步链接。
- `setup.md` 负责安装、依赖、环境变量和环境恢复。
- `architecture.md` 负责代码边界、数据归属与实际扩展位置。
- `learning.md` 负责练习顺序与每阶段验收目标，明确区分已实现与计划。
- `server.md` 负责服务器概念、本地运行和未来部署边界。
- `website.md` 负责网站页面、实际调用链和业务行为。
- `database.md` 负责数据归属、会话和迁移维护。
- 根 README 负责最短运行路径；不要在多个文件维护完整命令清单。
- 按职责补文档，不为每次聊天建立记录，不复制游戏项目的报告或门禁体系。
